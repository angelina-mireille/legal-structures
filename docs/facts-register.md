## Notes

1. Derived path facts fail closed (D33). A derived fact is TRUE when the graph shows a qualifying path, graded at the weakest grade on the strongest such path. It is FALSE only when a graded statement that the relevant record is complete supports it (a separate supplied fact, such as `software.lineage_declared_complete`), at that statement's grade. Otherwise it is UNKNOWN. A missing edge never makes a fact FALSE.
2. The graph holds no names. How an entity node is marked as the named source is for DS1/DS2.
3. Threshold facts (D29) are TRUE or FALSE from the compared values, graded at the weakest grade among their inputs, and UNKNOWN when any input is missing. Note 1 covers path facts (lineage, provider and control); a completeness statement is not needed for a threshold fact.
4. Completeness statements are inputs to the graph-to-facts mapping, not leaves in any rule's trigger.
